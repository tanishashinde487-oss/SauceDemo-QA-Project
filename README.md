# SauceDemo-QA-Project
## 📌 Project Overview

This is a manual QA testing project performed on the SauceDemo web application.

The purpose of this project was to practice and demonstrate real-world software testing activities, including test case design, test execution, defect identification, defect reporting, and evidence collection.

## 🧪 Testing Scope

The following areas were tested:

- Login and authentication
- Product listing
- Product sorting
- Product details
- Shopping cart
- Checkout
- Order completion
- Navigation

## 📝 Test Cases

A total of **25 manual test cases** were created and executed.

Testing included:

- Positive testing
- Negative testing
- Functional testing
- Boundary testing
- UI validation
- End-to-end checkout testing

All test cases and execution results are available in:

**SauceDemo Test Cases.xlsx**

## 🐞 Defects Found

A total of **5 defects** were identified during exploratory bug hunting.

The defects covered:

- Login/navigation behavior
- Incorrect product images
- Incorrect product details
- Product price mismatch
- Incorrect product displayed in cart

Screenshots have been included as evidence for each reported defect.

## 📸 Bug Evidence

The repository contains **8 screenshots** documenting the identified defects.

Each screenshot is named according to its corresponding bug ID for easy reference.
